# 自动阅读机器

用 Codex 定时任务处理本地书库。每本书交付一份可选字和批注的「全书梳理.pdf」，包含全书主线和逐章内容，和原书归到同一目录。

## 启动

1. 安装 Python 3.10+，执行 `python -m pip install -r requirements.txt`。
2. 用 `python extract.py "原书.pdf" "私有工作目录/原文.txt"` 提取并保留 PDF 页码。终端会列出无文本层的页码。扫描页需单独 OCR 或人工核读。
3. 在 Codex 中建立定时任务，复制 `automation-prompt.md` 并填入书库、工作目录及归档路径。当前工作流使用每 3 分钟触发，从记录的断点继续，运行期间避免重复处理。
4. 写好成稿后用 `python render.py "成稿.md" "书名/全书梳理.pdf" --font "中文字体.ttf"` 排版。成稿支持 Markdown 一级至三级标题与正文段落。

模型负责阅读、判断和写作。脚本负责提取与排版，定时任务负责续跑。此仓库不包含账号用量监控。书库、全文和进度请放在仓库外。
